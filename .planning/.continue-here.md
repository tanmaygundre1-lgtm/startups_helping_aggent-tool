## CRITICAL CONTEXT — Read First

### Project Overview

**StartupLink** is an AI-powered team-formation platform for student founders:

- Founders create startup ideas → AI extracts required skills/roles → System matches with skilled students → Teams form
- V1 MVP scope: Single complete end-to-end flow
- Tech Stack: React + Vite, Node.js + Express, MongoDB, Firebase Auth, Vercel AI SDK

## Critical Anti-Patterns (Do NOT Repeat)

| Pattern                   | Description                                              | Prevention                                                               |
| ------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------ |
| **Feature Creep**         | Adding "just one more" feature mid-phase breaks timeline | Strict phase gating: if not in ROADMAP.md phase scope, it's v1.1         |
| **Skipping Testing**      | "We'll test later" → end of timeline, no time for tests  | Test each endpoint manually as you build; critical paths need unit tests |
| **AI Integration Delays** | Vercel AI SDK complexity or response format issues       | Start Day 4 with simple prompt, iterate quickly, don't perfectionism     |
| **Schema Thrashing**      | Changing DB schema mid-phase → migrations, refactoring   | Design schema upfront from PLAN.md, lock in before Day 1                 |

## Additional Context

### Why Sequential Phases?

- Single developer can't parallelize effectively
- Each phase unblocks the next
- Reduces context switching and debugging complexity

### Why Strict MVP Scope?

- 2-week deadline is non-negotiable
- Each feature in ROADMAP.md v1.1+ deferred is time saved for robustness
- Post-MVP features (chat, tasks, advanced matching) can come after launch

### Why Vercel AI SDK?

- Built-in structured output support (Claude with JSON mode)
- Tool calling for agent workflows (future)
- Easier than raw API calls and prompt engineering
